# Conventions

- Prefer TypeScript and existing dependencies before adding packages.
- Keep domain logic in backend modules; clients focus on presentation.
- Version curriculum/content with source provenance; distinguish verified and AI-generated content.
- Distinguish observed evidence from AI inference.
- Protect critical academic state with auditability and controlled mutation.
- Enforce student isolation and parent/teacher consent boundaries.
- Record significant architecture changes in `docs/architecture/adr/`.
